# Contributing to Xe Key

Thanks for your interest. This project is **source-available, not open-source**
(see [LICENSE](LICENSE)): you may read the code and submit improvements, but you
may not use, run, distribute, or sell it.

## How to contribute

1. Fork the repo and create a branch.
2. Make your change. Keep it focused; match the existing conventions
   (`docs/conventions/`, Biome, kebab-case filenames).
3. Run the gates: `pnpm lint`, `pnpm typecheck`, `pnpm test`.
4. Open a pull request describing the change.

Forking and modifying your fork is permitted **only** to prepare a contribution
back to this project — not for your own use.

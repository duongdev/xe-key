Rules
WhenPIN sheet only when the user asks: Show places, or tapping a trip (opening details always needs the token). Never at sign-in. With Face ID saved, opening Trips runs Face ID by itself only if some listed trips have no saved places.
CachePlace names and trip detail (route, stats) are saved per trip on the phone once loaded; past trips never change. Saved places show in the list always, no PIN. Detail opens from the cache at once, but only after PIN or Face ID this session. Banner shows only while some listed trips have no saved places. App storage, no iCloud backup; deleted on sign-out and Forget PIN. No size limit (≈6 months of trips is small).
TokenpinToken lives in memory for the app session (like the Honda app). Killing the app forgets it: saved places still show, new ones and details wait for PIN or Face ID.
EntrySecure dots, system number pad, no Submit button: the 4th digit sends. Paste works; no OTP autofill. Delete edits; after a wrong PIN the next digit starts over.
WrongDots turn amber, status line says so, number pad stays. No shake, no attempt counter (Honda doesn't tell us).
LockedHonda's lock error: replace the pad with the locked view. Only way out is the Honda app.
Face ID offDefault. PIN is never stored.
Face ID onPIN in Keychain behind Face ID (ADR 0005 pattern, biometry-only access). Opening Trips with no token runs Face ID at once, once per app session (not on every visit, not from the background). Success → token → places fade in, no toast. Fail or cancel → frame 10; no auto-retry this session, Show places opens the sheet. Face ID changed (new face enrolled) → Keychain item is gone: same as off. Honda rejects the stored PIN → delete it, frame 9.
SettingsSecurity › Honda PIN: Face ID switch + Forget PIN (deletes Keychain item and the token).
HapticsDigits: none (keyboard). Checking: none. Success: success. Wrong / locked: warning. Face ID: system. Show places button: light (Button).
MotionSheet Settle 320 ms. Places cross-fade over times 200 ms per row, 30 ms stagger. Toast Pop. Reduce Motion: fades.
A11yDots: "PIN, 3 of 4 digits". Status line is a live region. Rows read places when unlocked, times otherwise.

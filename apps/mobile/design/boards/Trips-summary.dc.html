SourceGET /car/trip/summary?summaryType=Day|Month|Year, session only, no PIN (FINDINGS Round 9). Week = sum of the last 7 Day rows by date; Month = this month's Month row + its Day rows for bars; Year = Year row + Month rows for bars.
No scoreHonda has no driving score. The old score ring is gone.
Accel / brakeShown only when Honda sends a value above 0 for the period. 0 or null on every row → hide the bars, no empty state.
StatsDistance (sum), Time (sum, short form 4h12; under an hour 24 min), Avg speed (distance / time), Max speed (max), Fuel (Honda's km/l; distance-weighted average), Day / night as two percents with colour dots. Number 16 pt semibold, unit 12 pt fg2. VI labels: Quãng đường, Thời gian, Tốc độ TB, Nhanh nhất, Tiêu hao, Ngày / đêm; VI numbers use comma decimals (10,4).
RefreshPull to refresh on the list and on detail (light haptic at the threshold). Loading uses skeletons, never spinners.
SwitchSolid segmented control inside the card (content, not floating, so no glass). selection haptic on change. Bars grow from 0, Settle 240 ms; Reduce Motion: no grow.
HeaderTrip count and km pills removed: the card shows them.
EmptyPeriod with no trips: flat bars, stats show —, title "No trips this week".
BrowsePaged chart: drag the card body (title, bars, stats) sideways; it follows the finger and the earlier / later period shows beside it while dragging. Release past 25% or a fast flick snaps to it (Settle 300 ms), else springs back. Ends rubber-band. ‹ › do the same slide. Title shows the range (This week, Last week, 19–25 Oct; This month, October 2026). Back as far as Honda keeps Day rows (~6 months). selection haptic when a new period lands.
Swipe backOnly a left-edge swipe goes back (iOS edge gesture; full-screen swipe-back off on Trips). The pager starts 20 pt in from the edge, inside the card, so the two never meet. Pager uses a horizontal pan with activeOffsetX ±12 and failOffsetY ±10 so vertical scroll wins on vertical drags.
PrefetchWhen a period lands, fetch its neighbours (one earlier, one later) and keep them in the query cache, so the next drag shows real bars. Past periods never change: cache them for the session (persisted like other reads); only the current period refetches on focus / pull.
Bar tapSelects that day (month in Year): bar acc, others dim, list header "Mon 26 Oct · 2 trips" with Show recent. Tap again or Show recent → back to recent trips. Future days are faint and not tappable. No haptic (navigation). Trip list for a day: /car/trip?day=&month=&year= (no PIN).
ListWith no bar selected, the list stays recent trips, newest first. The list header is always there ("Recent trips" ↔ "Sat 31 Oct · 2 trips"), so tapping a bar never moves the rows.
No driftChanging period, range or bar keeps every box in place: card height fixed (same rows for Week / Month / Year), title centred between fixed 36 pt arrows, tabular digits, bars area fixed 64 pt. Accel / brake rows are decided per car (shown if Honda ever sent a value above 0), not per period, so they never pop in or out. A range not loaded yet shows skeleton bars and stats in the same boxes; a refresh keeps the values. See Trips-loading.
